# ASL Recognition System 🤟

This project is a Python-based American Sign Language (ASL) recognition system using Deep Learning.

## Features
- Train ASL model
- Predict hand signs
- Pre-trained model included
- Easy to run

## Requirements
Install dependencies:

pip install -r requirements.txt

## Dataset
Download the ASL dataset from:

https://www.kaggle.com/datasets/grassknoted/asl-alphabet

Place it like this:

dataset_asl_alphabet_train/
asl_alphabet_test/

## Train Model
python train.py

## Run App
python app.py
